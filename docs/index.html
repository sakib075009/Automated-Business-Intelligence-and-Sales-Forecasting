Analytics and forecasting

From descriptive analytics to forecasts

Sales performance

Examine revenue, profit, orders, monthly trends, regional results, product performance, and sales channels.

Customer and product insights

Explore purchasing behavior, customer summaries, product popularity, and differences across business segments.

Forecast evaluation

Compare forecasted and actual outcomes using MAE, RMSE, and MAPE. The seasonal-naive model provides a benchmark for further improvement.

Forecast metrics are evaluation results, not a guarantee of future accuracy. Interpret them in the context of the evaluation period and the underlying data.
Data and automation engineering

Designed for repeatable analysis

The workflow combines source-data validation, analytics generation, forecasting outputs, and downloadable run artifacts.

Technology stack

Python Pandas NumPy Scikit-learn Power BI DAX Git GitHub Actions Data validation Forecasting

1. Validate

Check source data, keys, relationships, dates, and financial calculations.

2. Analyze

Generate business summaries, visualizations, and forecast outputs.

3. Publish artifacts

Upload analytics outputs from successful GitHub Actions runs.

Current automation runs against the existing repository dataset. Persistent daily sales-data generation and automatic publication of refreshed data are separate future steps, not yet enabled in production.
